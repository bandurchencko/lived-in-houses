# Обжитые дома (Lived-in Houses)

**Генератор деревенских домов по правилам: планы этажей, комнаты, мебель и игровые проверки — для игр.** Дом выходит в
glTF за секунды, внутрь можно заглянуть в браузере, а в нашей игре он собирается прямо в Unreal Engine 5.

> *«Дом становится интересным, когда по его устройству можно представить жизнь внутри».* — Астра, наш ИИ-помощник по
> художественному направлению

[English](README.md) · **[Живой показ — открыть дом в браузере](https://bandurchencko.github.io/lived-in-houses/)** · **[Ролик, 50 с](https://bandurchencko.github.io/lived-in-houses/lived-in-houses.mp4)**

**Версия 0.3.3** (28 сентября 2026) — дом по своей картинке, показ с фактурами, двускатные крыши, объёмный камень, ремёсла дворов. [Что изменилось](CHANGELOG.md).

## За минуту

- **Для кого:** разработчикам игр и модов, которым нужны *сёла, в дома которых можно войти*, — ролевые игры, симуляторы
  жизни, градостроители, черновые уровни, опыты с ИИ-персонажами — и у кого нет месяцев на ручную лепку каждого дома.
- **Какую проблему решает:** ИИ «картинка → 3D» даёт красивые статуи без нутра, процедурные города — коробки, наборы —
  одни и те же двадцать домов. Здесь за секунду строится целый дом с комнатами, дверями, лестницами, мебелью и двором —
  и сам проверяет, что персонаж по нему действительно пройдёт.
- **Как пользоваться:** открыть [живой показ](https://bandurchencko.github.io/lived-in-houses/) (ничего не ставить) →
  или `pip install -r requirements.txt` и вывести дом в glTF для Unreal, Unity, Godot, Blender → или показать ему свою
  картинку и получить ближайший знакомый ему дом (`python -m generator_domov.obraz moj-dom.jpg`).
- **Что дальше:** развиваем его вместе с нашей игрой — новые семейства и облики, когда их потребуют наши сёла, — и
  будем выкладывать и другие инструменты, которые сделаем по ходу.

## Зачем мы это сделали

Мы делаем сказочный мир, где люди, NPC и персонажи с ИИ **живут в домах**. Дом там не декорация: открываешь дверь,
проходишь в зал, садишься за стол у очага, поднимаешься по лестнице в спальню. Значит, у каждого дома должно быть
настоящее нутро: осмысленные комнаты, двери, в которые проходит персонаж, лестницы, по которым можно подняться.

Прежде чем писать своё, мы перепробовали всё, что нашли:

- **ИИ «картинка → 3D»** (Tripo, TRELLIS.2, Hunyuan3D). Красивый дом за минуту — но это статуя: внутри сплошная
  масса, комнат нет, дверь нарисована. Войти нельзя.
- **Процедурный город движка** (Unreal PCG, City Sample). Улицы и фасады за секунды — но коробки без нутра и никакого
  ощущения деревни, где живут люди.
- **Готовые наборы домов.** Качество отличное, но десять–тридцать одинаковых домов: мир начинает выглядеть как
  копия копии, внутри часто пусто, и облик — чужой.
- **Руками из своих деталей.** Красиво и ровно в нашем облике — но дни на дом. Однажды мы два дня делали три дома.

Поэтому мы написали программу, которая **знает, как устроен дом**: какие комнаты нужны трактиру или семейному дому,
где очаг и стол, как идёт лестница, куда смотрят окна — и **сама себя проверяет** (персонаж доходит до каждой комнаты,
лестница проходима, окна не загорожены). Облик задаётся числами с рисунков художника — высота цоколя, размеры окон,
уклон крыши, материалы, — а каждое зерно даёт новый дом в том же облике. Один дом — около секунды до glTF и 8–30 секунд
до Unreal.

### Где пригодится

- **Ролевая игра, симулятор жизни, градостроитель**, где игроки и NPC заходят внутрь: трактиры, дома, мастерские,
  кузницы.
- **Быстрые черновые уровни с настоящим нутром** — проверять ходьбу, камеры и задания в домах, которые уже прошли
  проверки проходимости.
- **Опыты с ИИ-агентами и NPC**, которым нужны комнаты, чтобы жить и ходить.
- **Разнообразие для маленькой команды** — десятки разных домов одного облика без ручной лепки каждого.
- **Учиться процедурной архитектуре** — правила записаны обычным кодом, их можно читать и менять.

Не лучший выбор для фотореалистичных «главных» зданий (художник сделает лучше), современных городов (см. City Sample) и
отдельных предметов (там быстрее ИИ-генераторы и наборы).

### Почему брать

Бесплатно (MIT). Нутро и игровые проверки — сразу. glTF открывается в Unreal, Unity, Godot и Blender. Свой облик — это
набор чисел, а не новый конвейер художника. Два семейства для начала — и способ добавить свои виден прямо в коде.

## Что делает

Даёшь семейство, зерно и облик — получаешь целый дом, в который можно войти:

1. **Паспорт** — зерно выбирает числа внутри диапазонов облика (цоколь, окна, уклон и свес кровли…), композицию (у
   трактира их четыре: галерея, пристройка, угол, навес) и кровлю (вальма или двускатная со щипцами в фахверке).
2. **План этажей** — комнаты по программе (зал с очагом и общим столом, кухня, спальни, кладовая, мастерская или
   кузня), двери, окна, лестницы, крыльцо, галерея, двор, сарай, сад.
3. **Детали без движка** — стены с проёмами, полы, потолки, скаты, фахверк, окна со ставнями, черепица или камыш,
   живой камень (крупные угловые камни, неровный верх, парапеты лестниц с накрывными камнями, глыбы у подножия), мебель и мелочи — по группам: оболочка, перегородки, полы, кровля, мебель, мелочи (отдельными сетками — свет внутри
   держится чисто).
4. **Проверки** — капсула персонажа проходит в каждую комнату через каждую дверь, лестница проходима (≤ 38°, ступень ≤
   0,19 м, проступь ≥ 0,27 м), двери ≥ 0,95 м, у жилых комнат есть окна, от входа видны очаг и стол, окна не загорожены.
5. **Выход** — glTF/GLB примерно за секунду (этот репозиторий) или сборка в Unreal Engine 5 за 8–30 с на дом (сборщик
   нашей игры, см. ниже).

Сейчас два семейства: **трактир с кузницей** (четыре композиции) и **дом с двором** (крыльцо, сад или мастерская; сарай,
грядки, плетень), в двух обликах — **красный камень** (известь, тёмный брус, черепица) и **дом под камышом** (кремовая
глина, тёмный фахверк, толстый камыш). Все семь примеров проходят все свои проверки.

## От картинки к дому: кто что делает

Сам генератор картинок не смотрит. Он читает **паспорт**: семейство (трактир, дом с двором), части (крыльцо, сад,
мастерская, галерея) и **числа облика** — высоту цоколя, размеры окон, вид и уклон крыши, свесы, материалы и цвета.
Картинка входит на шаг раньше:

1. **Показываешь образец** — фотографию, набросок, концепт-арт — художнику. У нас это Астра (ИИ, который видит
   картинки) вместе с владельцем; так же может быть ты сам или любой ИИ, умеющий читать изображения.
2. **Художник переводит картинку в числа**: «красный каменный цоколь 0,6–0,9 м, окна 0,65–0,95 м со ставнями, вальмовая
   крыша 22–30°, галерея вдоль фасада». Это и есть файл облика (наш пример — `stil_mangala.py`).
3. **Генератор строит сколько угодно домов в этом облике** — каждое зерно даёт новый, у каждого настоящее нутро и
   пройденные проверки. Секунда на дом.
4. **Смотришь** (в браузере или в движке) и говоришь, что не так — меняются числа, а не дома.
5. *(следующие выпуски)* **Планировщик села** расставляет дома вдоль улиц, вокруг площади, по террасам.

### Дом по своей картинке

Теперь шаг с картинкой — тоже команда. **Глаза** — ИИ, который видит изображения, — читают картинку в паспорт, а
генератор строит ближайший знакомый ему дом: с настоящим нутром, с пройденными проверками, в цветах картинки.

```bash
python -m generator_domov.obraz moj-dom.jpg --glaza=vruchnuyu   # бесплатно: подсказку и картинку — в любой чат с ИИ, ответ — обратно
python -m generator_domov.obraz moj-dom.jpg --glaza=claude      # само: Claude Code (подписка Claude)
python -m generator_domov.obraz moj-dom.jpg --glaza=ollama      # бесплатно и без интернета: своя модель через Ollama (опытный)
python -m generator_domov.obraz moj-dom.jpg --glaza=api         # само: ключ Anthropic API, центы за картинку (опытный)
```

На выходе — `rab/obraz/<имя>/<имя>-dom.glb`, паспорт, который прочёл ИИ, и отчёт проверок. Файл `.glb` можно бросить
на [живую страницу](https://bandurchencko.github.io/lived-in-houses/) и обойти дом снаружи и внутри. **Самому
генератору не нужны ни ИИ, ни интернет, ни подписка** — глаза нужны только шагу с картинкой, и бесплатные подходят.

![Рисунок дома-кузни → дом генератора](docs/obrazy/obraz-dom-kuznya.jpg)
![Рисунок улицы → дом генератора](docs/obrazy/obraz-ulica-k-vode.jpg)

Два честных предела: генератор строит только то, что знают его правила (фотография собора даст ближайший знакомый ему
дом в цветах и пропорциях собора, а не собор), и нутра на картинке никогда не видно — его генератор придумывает сам, по своим правилам. В этом разница
с ИИ «картинка → 3D»: те копируют внешнюю форму и дают статую, а этот следует облику картинки и даёт дом, в котором
можно жить.

## Движки, форматы, требования

| | |
|---|---|
| **Запуск** | Python (проверено на 3.13) с `numpy`, `trimesh`, `pillow`; `pytest` — для тестов. Для генерации движок не нужен. |
| **Главный выход** | **glTF 2.0 (`.glb`)** — метры, ось Y вверх, вход смотрит в −Z; узел на каждую группу (*стены, перегородки, полы, крыша, мебель, мелочи, зелень, земля*) — крышу и стены можно прятать; PBR-материалы по местам (цвет, шероховатость, металл, светящиеся угли очага). 13–20 тысяч треугольников и меньше 1 МБ на дом. |
| **Ещё** | JSON каждого шага — паспорт, план (комнаты, двери, лестницы, части), список деталей, итоги проверок (`python -m generator_domov dom …`); листы планов картинками. |
| **Unreal Engine 5** | Перетащить `.glb` в Content Browser (импорт glTF). В нашей игре свой сборщик превращает те же детали в сетки Unreal через Geometry Script — сетка на группу, материалы с фактурами, свет — 8–30 с на дом (UE 5.8; в первый выпуск не вошёл). |
| **Unity** | Импорт `.glb` официальным пакетом glTFast. |
| **Godot 4** | Положить `.glb` в проект — импортируется сам. |
| **Blender** | File → Import → glTF 2.0. |
| **Браузер** | `docs/index.html` — просмотр на three.js (живой показ выше). |
| **Свой движок** | Список деталей — JSON простых тел без движка (коробки, стены с проёмами, брусья, скаты, профили, цилиндры, сферы, окна, черепица) — сборщик под любой движок укладывается в несколько сотен строк. |

**Фактуры:** в `.glb` есть развёртка (в метрах, по каждой грани — черепица идёт вдоль карниза, камень рядами) и ровные PBR-цвета; просмотр одевает дом фактурами CC0 с [Poly Haven](https://polyhaven.com) — камень, штукатурка, брус, черепица, камыш, мостовая — в оттенке цветов дома и освещает небом CC0 (`docs/tekstury/`). **Пока нет:** фактур внутри `.glb`, уровней детализации; семейств пока два.

## Быстрый старт

```bash
pip install -r requirements.txt
python -m pytest generator_domov -q                  # 333 теста, ~2 с
python primery.py                                    # примеры → docs/glb
python -m generator_domov.eksport_glb traktir 13 --kompoz=galereya --vyhod=traktir.glb
python -m http.server 8000 --directory docs          # и открыть http://localhost:8000
```

Код — рабочий код нашей игры, как есть: имена латиницей по-русски (`sobrat` — собрать, `detali` — детали, `proverki` —
проверки, `krysha` — крыша), комментарии по-русски.

Veloren, Shadows of Doubt и др. — список в [README.md](README.md#prior-art--we-are-not-the-first)). Готовым открытым
инструментом для UE5 мы не нашли именно сочетание: сельские дома с хозяйством по зерну, игровые проверки у каждого дома
и планировщик деревни на рельефе вокруг них (следующие выпуски).
